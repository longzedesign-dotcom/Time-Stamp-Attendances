## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

### 1. หน้าจอหลักและการลงเวลา (Smart Clock In/Out Hub)
- **แผนที่พิกัดจริงแบบเต็มจอ (Full-screen Map):** แสดงหมุดพิกัดผู้ใช้งานแบบ Real-time พร้อมจุด Pulse วงแหวนสีน้ำเงิน
- **ระบบ GPS Multi-sample Stabilization & Anti-Spoofing:** กรองความแม่นยำของดาวเทียม ป้องกันการโกงตำแหน่ง หรือพิกัดกระโดด
- **ระบบ Dynamic Accuracy Buffer:** คำนวณชดเชยค่าความคลาดเคลื่อน GPS ภายในอาคาร ทำให้ลงเวลาได้เสถียร ไม่หลุด Geofence โดยง่าย
- **การรองรับพื้นที่ทำงาน 2 จุด (Dual-Office Assignment):**
  - **สำนักงานใหญ่ (Main Office):** เช่น กระทรวง/สำนักงานใหญ่ (LOC001)
  - **สำนักงานประจำ (Site Office):** สาขา หรือหน่วยงานในสังกัด (LOC002)
- **กรอบเวลาลงเวลาตามระเบียบองค์กร (Attendance Time Windows):**
  - **06:00 - 08:30 น.:** ลงเวลาเข้างานปกติ (On Time)
  - **08:31 - 12:00 น.:** ลงเวลาเข้างานสาย (Late)
  - **13:30 - 20:00 น.:** ลงเวลาออกงาน (Check-out)
  - **ระบบป้องกันการกดซ้ำ (Duplicate Protection):** บล็อกการกดย้ำภายใน 60 วินาที
- **การ์ดวันเวลาแบบ Floating:** แสดงวันภาษาไทย เดือน ปี พ.ศ. พร้อมนาฬิกาดิจิทัล Real-time (เช่น *"วันจันทร์ 13 กรกฎาคม 2569  01:17"*)
- **ปุ่มแอ็กชันเด่นชัด:** ปุ่มคู่ขนาดใหญ่ `[ 🟢 ลงเวลาเข้า ]` และ `[ 🔴 ลงเวลาออก ]`
- **ปุ่ม Re-center GPS:** เล็งตำแหน่งพิกัดปัจจุบันกลับมากึ่งกลางหน้าจอได้ทันที
- **สลับโหมดการปฏิบัติงาน:** เลือกได้ระหว่าง `Onsite สำนักงาน`, `WFH (ปฏิบัติงานที่บ้าน)`, หรือ `นอกสถานที่ (Field Visit)`

### 2. ปฏิทินและประวัติการลงเวลา (Calendar & History View)
- ส่วนหัวระบุชื่อผู้ใช้งาน (เช่น *คุณ เฉลิมพร ถาโคตร*) และเวลาทำงานประจำกะ (*8:30 – 16:30*)
- **การ์ดสรุปสถิติประจำเดือน (Month Summary Cards):**
  - มาทำงาน (วัน)
  - มาสาย (วัน)
  - ออกก่อนเวลา (วัน)
  - ชั่วโมง OT รวม (ชม.)
- **ปฏิทิน พ.ศ. ภาษาไทย:** แสดงจุดไฟสถานะ (เขียว = เข้างาน, แดง = ออกงาน, เทา = วันหยุด/ยังไม่ลงเวลา) พร้อมคลิกเลือกวันเพื่อดูรายละเอียด
- **ประวัติการลงเวลาแบบกลุ่มวันที่:** พร้อมปุ่มกรองช่วงวันที่ (Filter Modal) ค้นหาประวัติตามช่วงเวลา
- **หน้ารายละเอียดการลงเวลา (Detail View):** แสดงรหัสบุคลากร, ชื่อ, เวลาบันทึก, แบดจ์สถานะ, พิกัด GPS, ที่อยู่สถานที่ และแผนที่ปักหมุดพิกัดจริง

### 3. ระบบยืนยันตัวตนและความปลอดภัย (Enterprise Security)
- รองรับการเข้าใช้งานด้วย **LINE Login**
- รองรับการเข้าใช้งานด้วย **Google Account**
- รองรับการเข้าใช้งานด้วย **รหัสสมาชิก / รหัสพนักงานบริษัท** พร้อมระบบป้องกัน Brute-Force (ล็อก 10 นาที หากกรอกผิดเกิน 5 ครั้ง)

### 4. ระบบการสื่อสารและศูนย์ช่วยเหลือ (Chat & Support Suite)
- **แชตภายในองค์กร (Internal Chat):** ส่งข้อความปรึกษา ประสานงาน หรือสื่อสารภายในระบบ
- **ศูนย์ช่วยเหลือและคำถามที่พบบ่อย (FAQ Knowledge Base):** ตอบข้อสงสัยเกี่ยวกับการลงเวลา ระเบียบองค์กร และการแก้ไขปัญหาพิกัด
- **HR Support Tickets:** ระบบเปิดเคสปรึกษาหรือแจ้งปัญหาต่อฝ่ายบุคคลโดยตรง

### 5. ระบบสายอนุมัติคำขอ (Correction & Overtime Workflow)
- **ขอปรับปรุงเวลา (Time Correction):** สำหรับกรณีลืมลงเวลาเข้า-ออก หรือมีเหตุจำเป็น พร้อมส่งสายอนุมัติถึงหัวหน้างาน
- **ขอทำงานล่วงเวลา (Overtime - OT):** ยื่นขออนุมัติทำโอทีล่วงหน้า คำนวณชั่วโมงอัตโนมัติ

### 6. การรายงานและส่งออกข้อมูล (Reports & Export)
- สรุปสถิติเวลาทำงานรายเดือน: วันทำงานจริง, จำนวนวันที่มาสาย, จำนวนครั้งที่ออกก่อน, ชั่วโมง OT รวม
- ส่งออกไฟล์ CSV พร้อม BOM รองรับภาษาไทยสมบูรณ์แบบบน Microsoft Excel สำหรับเชื่อมต่อฝ่ายบุคคลหรือระบบเงินเดือน (Payroll)

## 🗄️ โครงสร้างฐานข้อมูล Google Sheets (14 ตาราง)

| ตาราง | วัตถุประสงค์ |
| :--- | :--- |
| `Users` | ข้อมูลบุคลากร, แผนก, กะงาน, สิทธิ์ (Admin/Supervisor/User), รูปโปรไฟล์ |
| `Attendance` | บันทึกประวัติการลงเวลาจริง, พิกัด Lat/Lng, ระยะห่าง, แบดจ์สถานะ, รูปถ่าย |
| `Locations` | พิกัดสถานที่ทำงาน/สาขา (Latitude, Longitude, รัศมี Geofence เมตร) |
| `Sessions` | เซสชันการล็อกอินและ Session Token ป้องกันการสวมสิทธิ์ |
| `Notifications` | ประวัติการแจ้งเตือนภายในแอป (In-app Alerts) |
| `Departments` | รายชื่อสำนัก/กอง/ศูนย์ และหน่วยงานสังกัด |
| `Settings` | ค่าคอนฟิกูเรชันของระบบ |
| `Auditlogs` | บันทึกประวัติความปลอดภัยและการเข้าใช้งานระบบ |
| `Holiday` | ปฏิทินวันหยุดนักขัตฤกษ์และวันหยุดราชการประจำปี |
| `CorrectionRequests` | รายการคำขอลืมลงเวลา / ปรับปรุงเวลา พร้อมสถานะการพิจารณา |
| `OvertimeRequests` | รายการคำขออนุมัติทำงานล่วงเวลา (OT) |
| `ChatMessages` | ข้อความแชตสนทนาภายในระบบ |
| `FAQItems` | คลังความรู้ คำถาม-คำตอบที่พบบ่อย |
| `HRTickets` | เคสเปิดเรื่องสอบถามและข้อร้องเรียนฝ่ายบุคคล |

## 💻 โครงสร้างโค้ดโปรเจกต์ (Codebase Structure)

```text
Time Stamp Attendances/
├── .clasp.json                   # ตั้งค่า Clasp สำหรับ Deploy
├── .gitignore                    # ไฟล์ยกเว้น Git
├── README.md                     # เอกสารแนะนำระบบและฟังก์ชัน
├── INSTALL_GUIDE.md              # คู่มือการติดตั้งและตั้งค่า
└── src/
    ├── appsscript.json           # สิทธิ์การเข้าถึง (Drive, Sheets, Geolocation, Gmail)
    ├── Config.gs                 # ค่าคงที่, สคีมา 14 ตาราง, พิกัดสาขา, กะงาน
    ├── Utils.gs                  # ตัวคำนวณ Haversine GPS, จัดการรูปแบบ พ.ศ., SHA-256
    ├── Db.gs                     # Database Layer พร้อม LockService และ In-memory Cache
    ├── Setup.gs                  # ตัวสร้างตารางและตั้งค่าชีตอัตโนมัติ (Auto Schema Seeder)
    ├── Auth.gs                   # ล็อกอิน ThaID, MOC Account, Token และ Session
    ├── Attendance.gs             # จัดการลงเวลา, เช็ค Geofence, บันทึกรูปภาพ Selfie
    ├── Workflow.gs               # ระบบขอปรับปรุงเวลา และคำขอทำโอที (OT)
    ├── Chat.gs                   # แชตภายในองค์กร และศูนย์ช่วยเหลือ Q&A
    ├── Files.gs                  # บันทึกรูปภาพ Selfie ลง Google Drive อัตโนมัติ
    ├── Notify.gs                 # ส่งแจ้งเตือนผ่านแอปและอีเมล
    ├── Reports.gs                # สรุป Timesheet รายเดือน และ Export CSV สำหรับ Payroll
    ├── Admin.gs                  # แดชบอร์ดผู้ดูแล จัดการพนักงาน พิกัด และสิทธิ์
    ├── Code.gs                   # Web App Entry Point (doGet) และ Universal API Dispatcher
    └── Index.html                # Single Page Application (SPA) ถอดแบบ UI ตามรูปภาพ 100%
```
